# Orion Points — interactive concept

This private prototype preserves the supplied September 25, 2026 Orion Points snapshot: 8,772 available Points, 943 pending, 5,943 expiring, 9,715 total earned, zero redeemed, seven rewards, and ten activity entries.

Interactions include a draggable 3D reward collection, reversible reward cards, selected-reward chest reveals, account milestone trails, activity filters, expiry details, and responsive navigation. Reduced-motion preferences are respected.

Reward reveals are previews. They neither debit Points nor issue vouchers. Variable-price perks retain “From 1,500 Points”; no unavailable pricing formula is assumed. Other application areas are represented for context and are not connected to a backend.

The crystal and closed/open reward-case artwork are original generated assets inspired by the supplied visual references. Reward card frames and interface motion are implemented in the page.

Open `dist/index.html` with a static web server to preview locally. The site has no build step.
